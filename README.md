`njar` is an R port of the [NJA python
package](https://github.com/fwimp/NJA) for fitting graphs to images of
spatial networks.

## Installation

You can install the development version of `njar` like so:

``` r
# install.packages("pak")
pak::pkg_install("fwimp/njar")
```
