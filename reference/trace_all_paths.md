# Trace the path between all junctions in a binary map

Trace the path between all junctions in a binary map

## Usage

``` r
trace_all_paths(m, bordermat = NULL, juncmat = NULL)
```

## Arguments

- m:

  A binary map (matrix).

- bordermat:

  m, but with a 1 column and 1 row border of 0s. Generated by
  [border_matrix](https://fwimp.github.io/njar/reference/border_matrix.md)

- juncmat:

  A map of the number of junctions that each cell has. Generated by
  [map_junctions](https://fwimp.github.io/njar/reference/map_junctions.md)

## Value

A list of lists, will eventually return an NJANet object I think.

## Examples

``` r
if (FALSE) { # interactive()
m <- matrix(FALSE, 5, 5)
m[3,] <- TRUE
m[4:5,5] <- TRUE
trace_all_paths(m)
}
```
