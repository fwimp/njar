# Map the number of white pixels that each white pixel neighbours

Map the number of white pixels that each white pixel neighbours

## Usage

``` r
map_junctions(m, bordermat = NULL, adj_stack = NULL)
```

## Arguments

- m:

  A binary map (matrix).

- bordermat:

  m, but with a 1 column and 1 row border of 0s. Generated by
  [border_matrix](https://fwimp.github.io/njar/reference/border_matrix.md)

- adj_stack:

  A 3D array containing the stack of adjacencies for each pixel.

## Value

A matrix of the same dimensions as m, but with each cell containing the
number of neighbouring white pixels (if the cell itself is white)

## Examples

``` r
m <- generate_test_matrix(5)
map_junctions(m)
#>      [,1] [,2] [,3] [,4] [,5]
#> [1,]    1    3    3    0    0
#> [2,]    0    0    4    3    0
#> [3,]    0    0    3    0    0
#> [4,]    0    3    0    0    1
#> [5,]    1    0    2    2    0
```
