# Trace the path between two junctions over a binary map

Trace the path between two junctions over a binary map

## Usage

``` r
trace_path(m, startcoords, direction, bordermat = NULL, juncmat = NULL)
```

## Arguments

- m:

  A binary map (matrix).

- startcoords:

  A vector of the coordinates specifying the start of the path.

- direction:

  The direction to take the first step in (either a number 1:9 or a
  direction, e.g. 2 or 'w').

- bordermat:

  m, but with a 1 column and 1 row border of 0s. Generated by
  [border_matrix](https://fwimp.github.io/njar/reference/border_matrix.md)

- juncmat:

  A map of the number of junctions that each cell has. Generated by
  [map_junctions](https://fwimp.github.io/njar/reference/map_junctions.md)

## Value

A list containing the start and end coordinates of the path, the
distance travelled, and the path taken.

## Examples

``` r
if (FALSE) { # interactive()
m <- matrix(FALSE, 5, 5)
m[3,] <- TRUE
m[4:5,5] <- TRUE
trace_path(m, c(3,1), "e")
}
```
