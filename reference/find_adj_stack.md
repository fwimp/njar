# Find adjancencies by stacking shifted versions of a matrix

Find adjancencies by stacking shifted versions of a matrix

## Usage

``` r
find_adj_stack(m, bordermat = NULL)
```

## Arguments

- m:

  A binary map (matrix).

- bordermat:

  m, but with a 1 column and 1 row border of 0s. Generated by
  [border_matrix](https://fwimp.github.io/njar/reference/border_matrix.md)

## Value

A 3D array of the size of m with 8 layers. Each layer corresponds to the
pixel one pixel in a given direction of the moore neighbourhood.
